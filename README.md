##  Installation & Usage
### Recommended: Official Launcher (Fast & Automatic) 
The launcher does all the heavy lifting for you — **it automatically checks for new updates every time you open it**, downloading and installing missing patches so you never miss a new release or hotfix. 

1. Head over to the **[Releases Section](../../releases)**. 
2. Download the latest **`VsSonicEXEUnofficialLauncher.exe`**.
3. Run the Launcher — it will automatically download, extract, and check for updates. 
4. Click **START GAME** to launch directly into the mod!

### Alternative: Manual Setup (Standalone Build) If you prefer not to use the launcher: 
1. Download the standalone game build (`build.zip`) from **[Releases](../../releases)**. 
2. Extract the `.zip` archive to your preferred directory. 
3. Launch `Vs Sonic.exe` manually.
